## 一、行业顶尖标准（对标基准）

| 维度 | 行业顶尖能力（Harvey/小威AI+/北大法宝AI） | 量化指标 |
|---|---|---|
| 法源覆盖 | 法律/行政法规/司法解释/部门规章/地方性法规/指导性案例全层级 | ≥6 层级全覆盖 |
| 法源溯源 | 每条引用可溯源至权威数据库；标注现行/失效状态 | 引用溯源率 100%；现行标注 100% |
| 权威库接入 | 北大法宝/威科先行等 API 可配置接入 | 配置方法文档化 + 扩展接口 |
| 主动信息采集 | 检索前校验争议类型/关键事实/管辖地域/时间节点/检索目标 | 5 要素校验；信息不全主动追问 |
| 用户分层 | 普通人/法学生/专业律师/法官识别与匹配 | ≥4 层识别与输出粒度适配 |
| 五阶工作流 | 问题解析→层级检索→冲突适用分析→时效期限梳理→结构化报告 | 5 阶完整可追踪 |
| 类案检索 | 案例匹配/裁判逻辑提炼/争议焦点识别/相关性排序 | 类案列表按相关性排序 |
| 引用格式 | 标准法条引用格式 + 效力层级与适用优先级 | 格式合规率 100% |
| 推理透明 | 推理路径可见；每条结论对应法源；存疑标注 | 结论-法源一一对应；存疑显式标注 |
| 零幻觉 | 不静默编造结论 | 编造率 0（无法验证则标注） |
